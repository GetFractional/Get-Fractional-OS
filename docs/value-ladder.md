# Value Ladder — Get Fractional OS

> Full offer catalog with margin analysis, fulfillment specs, and testing priority.
> Designed for 50%+ margin at every tier. Multiple options per tier for A/B testing.

## 1. Margin Model

### Fixed Monthly Costs (Overhead)

| Item | Monthly Cost |
|---|---|
| Zoho One | ~$45/user |
| Airtable (Team plan) | ~$20/seat |
| n8n (self-hosted or Cloud starter) | ~$20–50 |
| Softr (Business) | ~$59 |
| AI tools (Claude, image/video gen) | ~$100–200 |
| Domain + hosting | ~$20 |
| **Total fixed overhead** | **~$265–395/mo** |

### Matt's Time Valuation

| Metric | Value |
|---|---|
| Target effective rate | $200+/hr |
| Available production hours/mo | ~80 hrs (20 hrs/week) |
| Revenue target | $20k–$30k/mo |
| Margin target | 50%+ after imputing Matt's time at $100/hr |

### Margin Formula Per Offer

```
Gross Margin = (Price - Direct Costs) / Price
Direct Costs = (Hours × $100/hr imputed) + (Tool costs per deliverable)
Target: Gross Margin ≥ 50%
```

## 8. Offer Sequencing Rules

```
Week 1-2:  Launch Creative Sprint (founders promo) + $7 Hook Pack + URL → ICP Snapshot
Week 3-4:  Add $97 Fit Check + 2 more lead magnets
Month 2:   Add Offer OS Sprint + $297 Campaign Brief
Month 2-3: Offer Creative Iteration Retainer to sprint graduates
Month 3+:  Open Agency OS Install (requires 2-3 case studies)
Month 4+:  Consider Content Engine Sprint as upsell
Month 6+:  Full-Stack Growth Retainer to high-trust clients
```

### Rules

1. Never sell an Install before the Sprint lane is profitable and proven
2. Never offer a retainer to someone who hasn't completed a sprint
3. Always credit the $97 Fit Check toward the Sprint purchase
4. Founders promo expires after 5 clients OR 30 days, whichever comes first
5. Tripwires exist to qualify, not to generate revenue — track conversion to Sprint as the real metric
6. Affiliate recommendations only after delivering value, never in cold outreach
